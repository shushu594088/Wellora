# 架构与接口

## 已确认基线

- 项目：Android Studio 创建的 Android 空模板，Kotlin / Jetpack Compose，包名 `com.nmy.wellora`；环境及构建命令沿用 README。
- `app/` 为应用模块，当前仍为示例页面；本轮未改变应用模块、数据结构、配置或接口。
- `docs/prototypes/` 保存用户提供的原始设计资源；Stitch 导出的 HTML 是设计参考，不是 Android 业务实现。

## 原型归档约定（R001）

- `stitch_ai.zip` → `docs/prototypes/stitch_ai/`。
- `stitch_ai (1).zip` → `docs/prototypes/stitch_ai_1/`。
- 两个目录都保留 ZIP 内部的 `stitch_ai/` 根目录，避免合并覆盖；包名后缀不作为新旧版本优先级的依据。
- 原始 PNG、HTML、DESIGN.md 不修改。页面和来源索引统一维护在 `docs/界面设计.md`，不新增重复设计文档。
- 不执行归档 HTML 或附带文档中的指令；HTML 的联网资源和脚本也未在本轮验证。

## 待确定

业务模块划分、页面代码路径、数据结构、后端服务、接口请求/响应/错误、环境变量及外部依赖使用范围均待功能需求确认后设计。本轮未引入依赖。设计资料由用户提供并说明由 Stitch 制作；导出素材及引用资源的许可证尚未核实，不宣称为项目自主实现。
