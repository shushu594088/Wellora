# P028：修复 Android Studio Debug 登录连接失败

- 用户反馈：Android Studio 登录显示“连接失败请检查网络”。
- 根因：`local.properties` 的 `wellora.apiBaseUrl` 为 `http://127.0.0.1:8000`；模拟器的回环地址不指向香港服务器。
- 修复：本机未跟踪配置改为 `https://api.shushu520.top`，不写入凭据、不提交 local.properties。
- 验证：BuildConfig 基址由 localhost 变为正式 HTTPS；后端健康 200；单元测试、Debug 构建、Medium Phone API 37 的 12 项服务器测试通过；服务器虚构账号已清理。
