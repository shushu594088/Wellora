问题
- Android Studio Debug 登录显示“连接失败，请检查网络”。
- `local.properties` 的 `wellora.apiBaseUrl` 原为 `http://127.0.0.1:8000`。
- Android 模拟器内的 127.0.0.1 指向模拟器自身，不是香港服务器，因此请求无法到达 API。

- 未写入凭据，未提交 `local.properties`。
- API 业务代码不变；请求仍使用 `/api/v1/auth/login`。
